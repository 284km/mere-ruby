# Rails-2: a superclass name fires the nearer autoload; a class's own #then answers before Kernel's

Two more causes from round 2 of activerecord (main 8c39dd51, 1,008 RED): 39 "wrong number of arguments" and 24 in FutureResult.

## A superclass name fires the nearer autoload (39)

`class ThroughAssociation < Association` in `ActiveRecord::Associations::Preloader`: the superclass's name is a constant read. `Preloader::Association` is an autoload there, and `Associations::Association` is already loaded one scope out. A read of the name loads Preloader's own. The class statement took the nearest scope that already HELD the name, so `Preloader::ThroughAssociation` became a subclass of `Associations::Association` and inherited its `#initialize`: "wrong number of arguments (given 6, expected 2)" for every preload through a has_many :through.

- **`near_autoload_fire`** asks whether an autoload of the name is registered in a scope nearer than the one that holds it, and loads it if so. Both keys are a prefix of the cref and then the name, so the longer is the nearer.
- **The class statement** asks it in both of its paths: `named_class_of_al` (the statement evaluator) and the class-body walker, which resolved the name with `resolve_scope_name` first.

Corpus 965 has the shape through a file an autoload loads, in a class body, in a nested body and through `eval`, and the case where no nearer autoload is. has_many_through_associations_test: 26 RED to 12, no MATCH lost; the 12 left are #197's cause (a table name selected as a column) but two.

## A class's own #then answers before Kernel's (24)

`recv.then { }`, `yield_self { }` and `tap { }` with a block ran Kernel's whatever the receiver's class defined: the block got the receiver itself.

`ActiveRecord::FutureResult::Complete#then` hands its `@result` on, and `FutureResult#then` makes a Promise. `result.then { |r| r.cast_values }` in a calculation got the wrapper: "undefined method 'cast_values' for an instance of ActiveRecord::FutureResult::SelectAll", and `columns`, `column_types` likewise.

- **`own_meth_named`** asks whether the receiver's own class chain defines the name. A class receiver's is its singleton's (`def self.then`), not the method its instances have.
- The three block arms step aside when it is true, and the call is dispatched to the class's method.

Corpus 966. calculations_test: 135 RED to 119, no MATCH lost; what is left there is #197's cause.
