# Rails-2 round 1: a Module subclass instance is self in its own module_eval and its #initialize

**Why.** The first activerecord run (sqlite3 adapter, 427 files, the fw-gems install from main 86d0b3e8) stopped 128 files on the mere-ruby side before their tests ran. Two causes account for 108 of them, and both come from one gap. The gap is an instance of a `Module` subclass acting as the module it is.

- **103 files: enum.** `ActiveRecord::Enum` builds `EnumMethods < Module`, includes an instance, and calls the subclass's private `define_enum_methods` from inside the instance's `module_eval`. The body ran with the anonymous module behind the instance as self (`mod_inst_backing`), so `self.class` was `Module` and the helper was missing. Every test whose models declare an enum stopped at load.
- **5 files: has_secure_password.** `ActiveModel::SecurePassword::InstanceMethodsOnActivation#initialize` calls `attr_reader attribute`. It was "undefined method 'attr_reader' for an instance of", with or without `self.`, and through `send`. The literal statement form (`attr_reader :x`) defined nothing at all.

**The change.**

- **`mod_inst_self`.** `module_eval`, `class_eval`, `module_exec` and `instance_eval` on such an instance bind self to the instance (a `VObj`), not to its backing module. They pass the instance as the block argument too. Methods defined inside still land in the backing, as before.
- **`extend` and `include?`.** `extend` takes the instance, as `include` already did; it was "wrong argument type (expected Module)". `include?` answers for it.
- **`mod_inst_delegates`.** It now covers `attr`, `attr_reader`, `attr_writer` and `attr_accessor`. These four are left out of `modmeth` on purpose, because they change which arm answers a call; here they are named for the instance only.
- **The statement form.** `attr_reader :x` in a method whose self is such an instance defines on it, as the call form does.

**Corpus 960** covers the module_eval and exec forms, the self and class seen inside, `extend` and `include?` on the instance, a cut-down enum, and the six `attr_*` forms in an instance's `#initialize`. It matches ruby 4.0.9.
